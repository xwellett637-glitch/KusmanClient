## 1. Общее описание

Kusman Client — модульный скрипт для игры [CURE] Violence District. Скрипт работает на клиентской стороне и не вмешивается в серверную логику. Все изменения визуальны или касаются локальных параметров персонажа.

Архитектура разделена на четыре файла:
- `loader.lua` — загрузчик, запускает остальные модули
- `config.lua` — настройки по умолчанию
- `core.lua` — основная логика (ESP, скорость, хитбокс, прицел)
- `gui.lua` — интерфейс меню и обработка горячих клавиш

## 3. Описание функций и принцип работы

### 3.1 Gens ESP (клавиша 1)

**Назначение:** Подсветка всех генераторов на карте.

**Механизм:** Скрипт выполняет обход всех объектов в `workspace` и ищет части, в названии которых присутствуют подстроки `generator` или `gen`. Для каждого найденного объекта создаётся экземпляр `Highlight` с жёлтым цветом. Обновление происходит один раз в 1.2 секунды.

**Цвет:** Жёлтый (RGB: 255, 255, 0)

### 3.2 Players ESP (клавиша 2)

**Назначение:** Подсветка игроков с цветовой дифференциацией.

**Механизм:** Скрипт анализирует каждого игрока и определяет его тип:
- Свой персонаж — белый (RGB: 255, 255, 255)
- Союзник по команде — голубой (RGB: 80, 180, 255)
- Враг из другой команды — оранжевый (RGB: 255, 140, 50)
- Убийца — красный (RGB: 255, 50, 50), но только если также включён Killer ESP

Для определения убийцы используются три критерия: наличие оружия (dagger, knife, blade), сравнение имени со списком из 30+ имён (Killer, Stalker, Slasher, Michael Myers и т.д.), проверка команды на соответствие строке `killer`.

### 3.3 Killer ESP (клавиша 3)

**Назначение:** Подсветка убийцы красным цветом независимо от состояния Players ESP.

**Механизм:** Использует ту же логику определения убийцы, что и Players ESP. При включении создаётся отдельный объект `Highlight` для персонажа убийцы.

### 3.4 Tiny Hitbox (клавиша 4)

**Назначение:** Уменьшение размера тела персонажа на 5%.

**Механизм:** Функция сохраняет оригинальные размеры всех `BasePart`, входящих в тело персонажа (Head, Torso, UpperTorso, LowerTorso, LeftArm, RightArm, LeftLeg, RightLeg, HumanoidRootPart). Затем каждому элементу присваивается новый размер, равный 95% от оригинала. При выключении функции размеры восстанавливаются из сохранённого состояния.

Дополнительно при активации создаётся едва заметный белый контур (прозрачность 85%), чтобы визуально обозначить активный режим.

### 3.5 Fast Turn (клавиша 5)

**Назначение:** Увеличение скорости поворота персонажа.

**Механизм:** Скрипт изменяет свойство `TurnSpeed` объекта `Humanoid`. Обычное значение — 120. При включении устанавливается значение 360. При выключении возвращается стандартное 120.

### 3.6 Crosshair (клавиша 6)

**Назначение:** Отображение статичного прицела в центре экрана.

**Механизм:** Используется API `Drawing`. Создаётся объект `Circle` радиусом 6 пикселей с толщиной линии 2. Внутри него создаётся точка (заполненный круг радиусом 1.5 пикселя). Позиция прицела привязывается к центру области просмотра камеры, которая пересчитывается при каждом изменении размера окна.

### 3.7 Speed Boost (ползунок в меню)

**Назначение:** Регулировка скорости бега.

**Механизм:** Изменяется свойство `WalkSpeed` объекта `Humanoid`. Диапазон значений от 16 до 50. При срабатывании нокдауна (функция `IsDowned` возвращает true) скорость принудительно устанавливается на 8, независимо от положения ползунка.

Определение нокдауна происходит двумя способами:
- Поиск `BoolValue` с именами `down` или `knocked`, имеющих значение `true`
- Проверка состояния `Humanoid` на соответствие `FallenDown` или `PlatformStanding`

### 3.8 Меню (клавиша F1)

**Назначение:** Скрытие и отображение графического интерфейса.

**Механизм:** При создании генерируется `ScreenGui` с тёмным фоном (RGB: 20,20,30). Каждый пункт меню представляет собой `TextLabel`, цвет которого меняется с красного (RGB: 200,80,80) на зелёный (RGB: 80,200,80) при активации функции.

Ползунок скорости реализован через `Frame`, обрабатывающий события `InputBegan` и `InputChanged` для перетаскивания мышью. Значение округляется до целого числа.

## 4. Редактирование чита

### 4.1 Изменение цветов ESP

В файле `core.lua` найдите функцию `UpdatePlayersESP`. Внутри неё присутствуют определения цветов:

```lua
color = Color3.fromRGB(255, 255, 255)  -- белый
color = Color3.fromRGB(80, 180, 255)   -- голубой
color = Color3.fromRGB(255, 140, 50)   -- оранжевый
color = Color3.fromRGB(255, 50, 50)    -- красный
```

Для изменения цвета достаточно заменить числовые значения RGB (от 0 до 255). Например, для жёлтого: `255, 255, 0`.

### 4.2 Изменение скорости ползунка

В файле `gui.lua` найдите строку:

```lua
local newVal = math.floor(16 + (50-16) * pos)
```

Значение 16 — минимальная скорость. Значение 50 — максимальная. Замените эти числа на желаемые.

### 4.3 Изменение степени уменьшения хитбокса

В файле `core.lua` найдите функцию `UpdateTinyHitbox`. В ней присутствует вызов:

```lua
K.SetBodyScale(char, 0.95)
```

Число 0.95 означает 95% от оригинала. Для более сильного уменьшения используйте 0.90 (90%) или 0.85 (85%). Не рекомендуется опускать ниже 0.85, так как персонаж начнёт заметно отличаться визуально.

### 4.4 Добавление новых функций

Новая функция должна быть добавлена в три файла:

1. `config.lua` — добавить ключ в таблицу `Settings` с начальным значением `false`
2. `core.lua` — написать логику работы функции и добавить её вызов в цикл
3. `gui.lua` — добавить пункт меню в таблицу `items` и обработку нажатия клавиши в `SetupHotkeys`

### 4.5 Изменение горячих клавиш

В файле `gui.lua` в функции `SetupHotkeys` находятся блоки:

```lua
if key == Enum.KeyCode.One then
    K.Settings.ESPGens = not K.Settings.ESPGens
    K.UpdateMenu()
```

Замените `Enum.KeyCode.One` на нужную клавишу. Доступные значения: `Enum.KeyCode.Two`, `Enum.KeyCode.Three`, `Enum.KeyCode.Four`, `Enum.KeyCode.Five`, `Enum.KeyCode.Six`, `Enum.KeyCode.F`, `Enum.KeyCode.R`, `Enum.KeyCode.Q` и другие.

## 5. Установка

Для запуска чита необходим инжектор (Xeno, Solara, Delta, Hydrogen). Скопируйте следующую строку и вставьте в поле ввода инжектора после подключения к игре:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/xwellett637-glitch/KusmanClient/refs/heads/main/loader.lua"))()
```

После выполнения появится меню в правом верхнем углу экрана.
